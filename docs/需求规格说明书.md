# 阅栈 ReadStack · 需求规格说明书

> 轻量化阅读管理 APP ｜ Xiaomi 17 定制版 ｜ v1.0.0
> 文档目的：收敛原始需求中的**模糊表述、逻辑冲突、缺失细节**，形成可直接开发与验收的唯一口径。

## 一、适配基线

### 1.1 机型参数（实测官方规格，非估算）

| 项目 | 参数 | 设计含义 |
|---|---|---|
| 屏幕尺寸 | 6.3″ 平面直屏（非曲面） | 无需做曲面边缘避让 |
| 物理分辨率 | 2656 × 1220 | — |
| 像素密度 | 460 ppi | DPR = 3 |
| **逻辑视口** | **406 × 884 pt** | **全部布局的唯一基准** |
| 屏幕比例 | 19.6 : 9 | 长屏，纵向内容区充裕 |
| 刷新率 | 1–120Hz LTPO | 动效需支持高帧率，避免掉帧感 |
| 触控采样 | 300Hz | 手势跟手性要求高 |
| 前摄 | 居中打孔 | 状态栏中央预留 11pt 挖孔区，禁止放内容 |
| 系统 | 小米澎湃 OS | 遵循其交互与视觉语言 |

### 1.2 布局栅格

```
屏幕宽 406
├─ 左右安全边距 18 ×2
└─ 内容区宽 370
   ├─ 卡片内边距 16 ×2
   └─ 卡片内容区 338   ← 图表 viewBox 宽度按此设计

垂直分区
├─ 状态栏      44pt（env(safe-area-inset-top) 兜底）
├─ 顶部导航     52pt（滚动 >34pt 后毛玻璃实心化）
├─ 内容滚动区   自适应
├─ 底部标签栏   58pt
└─ 手势条      22pt（env(safe-area-inset-bottom) 兜底）
```

### 1.3 全屏与无黑边策略

- 桌面/宽屏（>520px）：渲染等比例设备外壳，用于评审预览。
- 真机/窄屏（≤520px 或 coarse pointer）：**自动脱壳**，`100vw × 100dvh` 铺满，圆角与阴影全部移除。
- 使用 `viewport-fit=cover` + `env(safe-area-inset-*)`，兼容挖孔屏与全面屏手势区，**无黑边、无挤压、无截断**。
- 禁用双指缩放（`user-scalable=no`），避免误触导致版式错乱。

### 1.4 澎湃 OS 交互对齐

| 交互 | 实现 |
|---|---|
| 大标题折叠 | 页面顶部大标题随滚动淡出，导航栏渐变为毛玻璃 + 小标题 |
| 左缘侧滑返回 | 详情/编辑页左侧 22pt 热区，拖拽跟手，位移 >88pt 触发返回 |
| 底部动作表 | 圆角浮起 Sheet，带遮罩，点遮罩关闭 |
| 触感反馈 | 关键操作 `navigator.vibrate`（8/12/16/20ms 分级） |
| 弹性滚动 | `overscroll-behavior: contain`，防止穿透 |
| 动效曲线 | `cubic-bezier(.28,.78,.32,1)` 阻尼感，时长 180/280/420ms 三档 |

## 二、原始需求问题清单与收敛决策

> 这是本文档最重要的部分。原始需求共识别出 **14 处**问题，逐条给出裁决。

### 2.1 逻辑冲突（必须裁决，否则数据会乱）

| # | 冲突点 | 裁决 |
|---|---|---|
| C1 | 库存台账有「已读」状态，同时又存在独立的「已读清单」模块——两者是否同一份数据？ | **不是。** 库存状态只是藏书的物理属性标记；已读清单是独立的阅读行为记录。二者**物理隔离**：独立存储键、独立 ID 空间、独立 CRUD，**不存在任何自动同步**。 |
| C2 | 若完全隔离，用户读完一本藏书要重复录入两次 | 提供**显式的一次性字段填充**：藏书详情页「登记为已读记录」按钮，复制书名/作者/分类/封面到新建表单，**复制完即断开关系**，二次编辑互不影响。操作前弹窗明示此规则。 |
| C3 | 删除一方是否影响另一方？ | 不影响。删除确认文案中**明确告知**"不影响另一侧同名记录"。 |
| C4 | 库存里的书不一定读过，读过的书不一定在库存（借阅/电子书）| 已读清单增加**阅读载体**字段（纸质书/电子书/有声书），承认二者集合本就不重合。 |

### 2.2 表述模糊（需给出可执行定义）

| # | 模糊点 | 收敛定义 |
|---|---|---|
| A1 | "粉蓝渐变" 到底怎么渐变 | 固定为 `135° #A9D3FF → #C6C8FF(46%) → #FFC0DD`。中段插入淡紫过渡色，避免蓝粉直接对撞产生脏灰。 |
| A2 | "月度/年度报告" 按什么日期归期 | **统一以「读完日期 finishDate」归属**。开始日期只用于计算耗时。 |
| A3 | "智能偏好分析" 的智能程度 | 明确为**本地规则引擎**，不调用任何模型/网络。输入：分类分布、作者复现、评分分布、耗时、摘抄密度、载体；输出：5 段自然语言小结 + 关键词云。 |
| A4 | "阅读统计" 统计哪些指标 | 见 §6 统计口径表，共 11 项，每项给出计算公式。 |
| A5 | "加载速度快、占用内存低" | 量化为：零三方依赖、首屏 <0.5s、单页渲染 <16ms、封面统一压缩至 360×480 JPEG(q0.84)。 |

### 2.3 细节缺失（补充）

| # | 缺失项 | 补充方案 |
|---|---|---|
| M1 | 没有读完日期的记录怎么办 | 允许留空，**仅计入全域总量，不进入月/年报告**。详情页与全域报告均高亮提示待补。 |
| M2 | 评分是否必填 | 非必填。未评分记录**不参与平均分计算**，避免 0 分拉低均值。 |
| M3 | 分类是否允许自定义 | 不允许。固定 12 类枚举，防止自由输入导致统计口径分裂。 |
| M4 | 摘抄的归属与结构 | 摘抄是阅读记录的**子集合**，字段：正文（≤2000 字）、页码（选填）、创建时间。支持增删改，提供跨书「摘抄墙」聚合视图。 |
| M5 | 封面裁剪比例与失败兜底 | 固定 3:4；无封面时用**书名首字 + 渐变色块**占位，不留空白框。 |
| M6 | 存储写满怎么办 | 捕获 `QuotaExceededError`，提示"精简封面图"；受限环境（如 file://）自动降级内存存储并提示。 |
| M7 | 卸载前备份如何落地 | 「我的」页提供 JSON 导出；恢复支持**覆盖导入 / 合并导入**（按 id 去重），非法文件拒绝并提示。 |

## 三、视觉规范

### 3.1 色彩

| 用途 | 值 |
|---|---|
| 页面底色 | `linear-gradient(180deg, #EDF5FF, #F3F6FF 38%, #FDF4F9)` 清透浅蓝起、柔粉收 |
| 主渐变（导航/按钮/选中态） | `135deg, #A9D3FF → #C6C8FF 46% → #FFC0DD` |
| 卡片 | `140deg, #FFFFFF → #FBFCFF 52% → #FFF7FB` + 1px 白色描边 |
| 文字 | 主 `#1B2439`／次 `#56637F`／辅 `#8B96AE`／占位 `#AEB7C9` |
| 状态色 | 未读 `#8CA6C9`｜在读 `#6BA6F0`｜已读 `#4FC08D`｜弃读 `#C6A6D8` |
| 星级 | `#FFB13D` ｜ 危险 `#F2668B` |

> 护眼约束：正文与背景对比度 ≥ 7:1；渐变饱和度上限 S≤35%，不使用纯白 `#FFF` 大面积铺底，避免高亮度 AMOLED 下刺眼。

### 3.2 字阶与行距

| 层级 | 字号 | 用法 |
|---|---|---|
| Hero | 30 / 800 | 页面大标题 |
| H1 | 21 / 700 | 详情书名、弹窗标题 |
| H2 | 17 / 700 | 卡片标题、导航小标题 |
| H3 | 15 / 600 | 列表书名、按钮 |
| Body | 14 / 400 | 正文，**行距 1.68** |
| Small | 12.5 | 辅助信息 |
| XS | 11 | 标签、图例 |

字体栈优先 `MiSans`（澎湃 OS 系统字体），回退 HarmonyOS Sans → PingFang SC → system-ui。

### 3.3 形状与投影

圆角：8 / 12 / 16 / 22 / 28 / 999（澎湃 OS 大圆角语言）
投影：`0 2px 8px` / `0 6px 20px` / `0 14px 38px`，色相统一 `rgba(96,128,184,·)`，**不使用纯黑投影**（会发灰）。

## 四、信息架构与功能边界

```
阅栈 ReadStack
├── 库存（藏书台账）      ← 独立数据源 A
│   ├── 状态/分类筛选、4 种排序
│   ├── 藏书详情：信息栅格 + 状态流转 + 一次性填充入口
│   └── 登记/编辑：11 字段 + 封面裁剪
├── 已读（阅读台账）      ← 独立数据源 B
│   ├── 阅读清单 / 摘抄墙（分段切换）
│   ├── 记录详情：评分 + 感悟 + 摘抄集合
│   └── 登记/编辑：10 字段 + 星级 + 长文本感悟
├── 报告
│   ├── 全域总报告：核心指标 + 分类环形 + 评分分布 + 年度趋势 + 作者榜
│   ├── 月度报告：环比 + 阅读日历热力图 + 本月书单
│   ├── 年度报告：月度柱状 + 分类构成 + 高分书单 + 作者榜
│   └── 智能偏好分析（三种报告下均生成）
└── 我的
    ├── 备份导出 / 恢复导入 / 存储占用
    ├── 分类说明 / 示例数据 / 清空数据
    └── 关于与设计边界
```

**明确不做**（轻量化底线）：账号体系、云同步、社交、书城、广告位、开屏页、推送、积分打卡、阅读器内核。

## 六、报告统计口径

| 指标 | 公式 / 定义 |
|---|---|
| 累计读完 | 阅读记录总条数（含未填读完日期） |
| 周期本数 | `finishDate` 落在该月/年的记录数 |
| 平均评分 | Σrating / count(rating>0)，**排除未评分** |
| 本均天数 | Σ(finishDate−startDate+1) / count(有效区间)，同日读完记 1 天 |
| 摘抄总数 | 所有记录 excerpts 长度之和 |
| 分类构成 | 按 category 分组计数，降序 |
| 评分分布 | 1–5 星各自计数 |
| 年度趋势 | 按 finishDate 年份分组 |
| 月度分布 | 指定年份 12 个月计数，自动高亮峰值月 |
| 环比 | 本月本数 − 上月本数 |
| 阅读日历 | 当月每日读完量，5 级色阶热力图 |

**一致性保证**：月度分布合计恒等于年度总量（已写入自动化测试）。

## 七、非功能需求

| 项 | 指标 | 实现 |
|---|---|---|
| 依赖 | 0 个三方库 | 原生 JS/CSS/SVG，图表自研 |
| 首屏 | ≤0.5s | 单页无路由请求，脚本总量 <60KB |
| 单帧 | ≤16ms | 列表整段字符串渲染，无逐节点操作 |
| 列表滑动 | 无卡顿 | 卡片进场动画上限 240ms 且封顶，避免长列表堆叠 |
| 存储 | 本地永久 | localStorage；受限环境降级内存并提示 |
| 隐私 | 无网络请求 | 无埋点、无外链、无 CDN 字体 |
| 安全 | XSS 防护 | 所有用户输入渲染前统一 HTML 转义 |
| 异常 | 全兜底 | 空态、超限、非法备份、日期逆序、记录不存在均有明确文案 |
